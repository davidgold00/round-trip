# Glossary

| Term | Meaning here |
|---|---|
| Backlog | Future business a supplier has contracted but has yet to deliver. |
| RPO | Remaining performance obligations, revenue from customer commitments the company has yet to recognize. |
| Round trip | A seller finances a buyer that commits to purchase from that seller. |
| Edge, node | One directed financial relationship and a company at either end. |
| Provenance | The share of a buyer's documented funding attributable to a given seller. |
| Coverage | How much of the backlog denominator can be tied to named customers. |
| T1 / T2 / T3 / T4 | SEC filing / company release / reputable third-party report / unverified claim. |
| EDGAR / accession | The SEC filing archive and the identifier of an individual submission. |
| IR / GDELT | Investor relations releases and a news discovery service. |
| XBRL | Machine-readable financial facts attached to filings. |
| Letter of intent | Preliminary, potentially nonbinding statement of intended terms. |
| Cascade / pass-through | A shock propagates through buyers and sellers. Pass-through controls how much lost funding reduces purchases. |
| Eisenberg-Noe | A clearing model that solves how much each participant can pay given resources and incoming payments. |
| DebtRank | A cross-check that propagates distress along weighted network links. |
| Monte Carlo / tornado | Repeated draws of assumptions / a chart showing one-at-a-time sensitivity. |
| Triage / alias | A relevance screen / a different name for an existing company. |
| Schema / verifier | Required output fields and types / deterministic tests of the proposal against the source. |
| Reconcile | Compare a proposed deal with existing relationships for a duplicate, update or new obligation. |
| Precision / recall / F1 | Correct proposals divided by all proposals / found gold edges divided by all gold edges / their harmonic mean. |
| Gold / dev / test | Curated expected answers / passages for investigating changes / a frozen comparison set. |
| Ablation | Change one component and compare against the same prior configuration. |
| Cassette / replay | A saved sequence of exact generation requests and responses / running those responses through the pipeline again. |
| Calibration | Whether predictions assigned a given confidence prove correct about that often. |
